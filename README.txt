# إعلاناتي — منصة كاملة بحسابات ولوحة تحكم

## ⚠️ نقطة مهمة قبل كل شيء
أنا (Claude) أعمل داخل بيئة معزولة بدون اتصال إنترنت خارجي وبدون صلاحية نشر المواقع على الإنترنت مباشرة. لهذا **لا أستطيع إعطاءك رابطًا جاهزًا للمشاركة الآن**. لكنني بنيت لك المنصة كاملة وجاهزة للتشغيل، وما عليك سوى "رفعها" على خدمة استضافة مجانية لتحصلي على رابط حقيقي تشاركينه مع أي شخص. الخطوات أدناه بسيطة ولا تحتاج خبرة تقنية.

## ما هي هذه المنصة؟
موقع كامل (وليس ملفًا واحدًا كالسابق) به:
- صفحة رئيسية بها تسجيل دخول / حساب جديد للزوار.
- لوحة "إعلاناتي" لكل زائر: ينشئ إعلانه، يحفظه، يعدّله، يحمّله كصورة PNG احترافية بإطار وشعار — كل ذلك يعمل حتى بدون إنترنت بعد فتح الصفحة.
- لوحة تحكم للمشرف: عرض كل إعلانات الزوار، اعتمادها أو رفضها أو حذفها، وإدارة حسابات الزوار (إيقاف/تفعيل/حذف).
- شعار داخل الموقع، وأيقونة احترافية (بيت ذهبي على خلفية كحلية) تظهر عند "إضافة إلى الشاشة الرئيسية" على الجوال أو "تثبيت التطبيق" على الحاسوب، تمامًا كأي تطبيق حقيقي.
- أيقونات ذكية تلقائية لكل عنصر تكتبينه في "المميزات" (مثلاً: غرفة → 🛏️، مطبخ → 🍳، حديقة → 🌳، مسبح → 🏊، موقف سيارة → 🚗... إلخ).

## بيانات دخول المشرف الافتراضية
- البريد الإلكتروني: `admin@example.com`
- كلمة المرور: `Admin@12345`

**مهم جدًا:** غيّري هذه البيانات فور نشر الموقع (من الاستضافة يمكنك تعيين قيم مختلفة قبل التشغيل — انظري الخطوة 3 أدناه)، أو سجّلي دخولًا بها ثم استخدمي نفس آلية الدخول لاحقًا (لا توجد شاشة لتغيير البريد حاليًا، لكن يوجد تغيير كلمة مرور عبر واجهة API إن احتجت لاحقًا).

## كيف تحصلين على رابط حقيقي؟ (خطوات بسيطة عبر Render.com — مجاني)

1. أنشئي حسابًا مجانيًا على **render.com** (يمكن التسجيل مباشرة عبر حساب Google أو GitHub).
2. ارفعي محتوى هذا المجلد إلى مستودع GitHub جديد (أو استخدمي خيار "Deploy from a Git repository" في Render بعد ربط حسابك بـ GitHub ورفع الملفات هناك أولًا عبر واجهة GitHub نفسها — لا تحتاجين أوامر Git معقدة، يوجد زر "Upload files" في GitHub).
3. من لوحة Render: **New → Web Service** ثم اختاري المستودع الذي رفعتِه.
   - Build Command: اتركيه فارغًا (لا توجد مكتبات خارجية).
   - Start Command: `node server.js`
   - في قسم Environment Variables (اختياري لكن يُنصح به) أضيفي:
     - `ADMIN_EMAIL` = بريدك الذي تريدينه للمشرف
     - `ADMIN_PASSWORD` = كلمة مرور قوية من اختيارك
4. اضغطي **Create Web Service**. بعد دقيقة أو دقيقتين سيعطيك Render رابطًا مثل:
   `https://elanaty-xxxx.onrender.com`
   هذا هو الرابط الذي تشاركينه مع أي شخص ليدخل الموقع، ينشئ حسابًا، ويضيف إعلاناته.

> بديل أسهل إذا كان لديك خبرة بسيطة بـ GitHub: يمكن استخدام **Railway.app** بنفس الطريقة تقريبًا (New Project → Deploy from GitHub → Start Command: `node server.js`).

## ملاحظة مهمة عن حفظ البيانات
المنصة تحفظ الحسابات والإعلانات في ملفات JSON بسيطة داخل مجلد `data/` (بدون قاعدة بيانات خارجية) لتبقى سهلة التشغيل بدون إعدادات معقدة. هذا ممتاز للتجربة والاستخدام الفعلي بعدد زوار معتدل. في Render (الخطة المجانية تحديدًا) قد يُعاد تشغيل الخادم من حين لآخر وتُفقد الملفات المحفوظة محليًا إن لم تُفعّلي **Persistent Disk** (متاح في الخطط المدفوعة البسيطة). إن أردت الاستخدام الجاد على المدى الطويل بعدد زوار كبير، أخبريني وسأجهّز نسخة تستخدم قاعدة بيانات حقيقية (مثل PostgreSQL المجانية من Render نفسها).

## هيكل الملفات
```
server.js            الخادم (Node.js — بدون أي مكتبات خارجية)
package.json          
public/
  index.html          الصفحة الرئيسية (تسجيل الدخول / حساب جديد)
  app.html            لوحة الزائر (إنشاء/تعديل/تحميل الإعلانات)
  admin.html          لوحة المشرف (مراجعة الإعلانات وإدارة الحسابات)
  poster-engine.js    محرك التصميم المشترك (الألوان، تخطيطات الصور، التصدير كصورة)
  shared.css          التنسيق العام المشترك بين الصفحات
  manifest.json       ملف "تثبيت كتطبيق" (PWA)
  icons/              أيقونة الموقع بجميع المقاسات + الفافيكون
data/                 يُنشأ تلقائيًا عند أول تشغيل (المستخدمون + الإعلانات)
```

## هل جرّبتِ الموقع فعليًا قبل تسليمه؟
نعم — تم اختباره بالكامل داخل بيئة محلية (وليس فقط قراءة الكود): تسجيل زائر جديد، إنشاء إعلان بعدة صور وحقول طويلة، حفظه، تسجيل دخول كمشرف، رؤية الإعلان، اعتماده، معاينته، إيقاف حساب زائر والتأكد أنه لا يستطيع الدخول بعدها، وتحميل صورة PNG فعلية من كل من لوحة الزائر ولوحة المشرف — كل هذا يعمل بدون أخطاء.
